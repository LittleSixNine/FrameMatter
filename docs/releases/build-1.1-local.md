# FrameMatter Build 1.1 — 本机临时版

新增独立齿孔漏光与十种大范围漏光，强度100%允许冲白。四种新增素材为34橙色窄光带、39无色柔光、15青绿色光雾和23蓝紫色光雾。

- 应用版本1.0.0，构建号1.1；关于窗口显示Build 1.1。更新检查沿用父级正式构建号1，后续Build 2仍能被识别。
- 使用 `Tools/package.sh --local` 生成 `FrameMatter-Build-1.1-arm64.dmg`，保留已确认的安装背景和拖拽布局。
- 含本机私有漏光贴图，仅供此次本地测试。素材原件与处理贴图不进入Git；公开再分发许可尚未核实。
- 本地ad-hoc签名，未公证；不上传GitHub，不替换已安装应用。Apple silicon、macOS 15及以上。
- 默认发布命令继续拒绝携带上述私有素材。本地打包不使用Developer ID或公证凭据。
