# 旧含脸v2定向优化：阶段A有限补回结果

2026-11-10。**v1仍为当前候选，研究优化起点是用户认可的旧含脸v2，不是v2.1。** 本阶段完成一版冻结的v2.2-face有限补回实验；不修复检测、不消费分区检测框、不与其他候选组合、不看图回调常数。

## 单因素范围与实际消费

冻结方程见 [阶段A公式](relative-face-meter-candidate-v2-2-restore.md)，私有同文副本SHA256 `536fb290dd93da4c8850268017bfd86b3cd01eb82ec1e474c8dd2e0a61ae2abe`。

完整复用旧v2的shadow0解码、相对场景2EV预算、Vision原1600全图检测、资格/最大脸/中心60%采样、旧gray+.5EV目标和Eb+1上限。唯一变化是成功测得脸后向同shadow0 balanced补回最多0.5EV；旧v2已提至Eb或以上者不变，无脸者不变。

新的隔离build从冷源/home重新解码、检测、取Y、测量旧完整方程并执行补回，不读取旧输出或预测EV。全部16张通过真实应用CLI让引擎消费源文件全尺寸，再正常导出1024长边sRGB JPEG。逐图核对实际native EV、comp0、产品print exposure compensation=false、shadow0、baseline/decoder exposure0/as-shot WB和完整参数；Portra 400/Supra与默认grain/halation/glare均不变。所有旧Eb/场景量/最大脸/旧中心样本/脸目标与旧v2统计匹配至1e-9。

对照A为原v1 JPEG、B为旧含脸v2 JPEG，逐字节复制并核对哈希；C为本轮新有限补回。v1与B/C的RAW解释不同，跨臂差不能说成纯测光单因素。B→C是本阶段单因素对照，但随机glare及JPEG仍限制细微像素差的归因；曝光不变不等于JPEG逐像素相同。
