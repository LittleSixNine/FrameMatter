# FrameMatter Build 1.3 — 本机测试包

- 应用版本1.0.0，构建号1.3。
- 左栏在“划痕与灰尘”下方新增独立“做旧纹理”，默认关闭，启用强度默认50%。
- 五款完整做旧贴图，支持0–100%线性滤色强度、左右／上下／双向镜像，以及0／90／180／270度旋转。横竖图等比铺满，不拉伸；纹理随照片保存，预览和导出共用原生渲染路径。
- 可与现有随机灰尘、片边磨损及41款全局漏光同时使用。独立状态和纹理缓存；关闭或0%严格旁路，旧配方默认不启用。数字中间片导出排除该效果。
- 保留Build1.2确认的方案六DMG外观；仅Apple silicon、macOS15及以上。
- `Tools/package.sh --local` 生成本地ad-hoc签名安装包，不公证、不推送或公开发布。五款做旧及41款漏光的本体保留在本地忽略目录，来源和校验值跟随本地manifest；未确认公开分发／商用许可，正式发布拦截保留。

## 实际验证与边界

做旧实现已通过47项相关应用测试，另8项做旧／Agent测试（其中3项重复）；原生Metal专项覆盖滤色强度、画幅、镜像旋转、错误边界、底片缓存与DI导出。41款原有漏光回归、GPU smoke、数学精度守卫通过。用最终Debug应用资源生成五款0/50/100%及16种方向组合，灰尘＋漏光＋做旧叠加时孔内保持不变。

本次构建号变更补跑更新、许可与做旧设置测试。最终Release安装包重新挂载检查版本、签名、46份本地纹理、着色器、DMG背景及Applications链接，并生成SHA256。验证记录保存在本机`pravite/Build-1.3-验证/`。不替换已安装应用；未跑完整应用测试套件、未在其他Mac验收，Python参考引擎parity仍受参考包缺失限制。
